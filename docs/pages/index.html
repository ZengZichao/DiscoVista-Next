Overview

DiscoVista-Next is a complete Python 3 rewrite of the original DiscoVista (Discordance Visualization Tool), written by Erfan Sayyari and Siavash Mirarab on a mixed Python 2 + R stack. This version reimplements every R dependency (ggplot2, reshape2, plyr, ape, optparse, …) in Python 3 and adds a graphical interface built on qt-material.

It provides six analysis modes for phylogenetic discordance, supports both command-line and graphical workflows, and ships with example data from the 1KP plant dataset — making it easy to reproduce published figures and apply the tool to new datasets.

Key Features

🐍

Pure Python 3

No R installation or R packages required. All dependencies are pip-installable.

📊

Six Analysis Modes

Species tree discordance, gene tree discordance, GC content, occupancy, branch statistics, and relative frequency.

🎨

Complete Visualization

matplotlib + seaborn replace ggplot2, producing publication-ready figures.

🖥️

Graphical Interface

Modern qt-material GUI with 26 built-in color themes and bilingual (EN/ZH) support.

⌨️

CLI Compatible

Command-line interface compatible with the original DiscoVista argument format.

📦

Standalone Executable

Build a self-contained exe that runs without a Python installation.

Analysis Modes

Mode Analysis Description
-m 0 Species Tree Discordance Visualize discordance between species trees and gene trees at defined clades.
-m 1 Gene Tree Discordance Analyze gene tree discordance patterns across model conditions.
-m 2 GC Content Plot GC content distribution across sequences and taxa.
-m 3 Occupancy Display taxon occupancy across gene alignments or model conditions.
-m 4 Branch Statistics Plot branch support versus branch length for phylogenetic trees.
-m 5 Relative Frequency Analyze the relative frequency of bipartitions across bootstrap replicates.

Quick Start

Installation

From PyPI (recommended for users)
pip install discovista-next
From source (recommended for development)
git clone https://github.com/ZengZichao/DiscoVista-Next.git
cd DiscoVista-Next
pip install -r requirements.txt
pip install -e .

Command Line

Species tree discordance (mode 0)
discoVista -m 0 \
  -c examples/1KP/parameters/clade-defs.txt \
  -p examples/1KP/species/ \
  -t 95 -o results/
GC content analysis (mode 2)
discoVista -m 2 \
  -p examples/1KP/GC/unfiltered/ \
  -o results/

Launch the GUI

discoVista-gui
# or
python -m discovista_next.gui.main
Standalone executable: Run DiscoVista-Next.exe directly — no Python installation needed. Build it with python build_exe.py.
